# NestForge CLI

The official NPM distribution for the [NestForge](https://github.com/vernonthedev/nestforge) Rust framework CLI.

## Installation

```bash
npm install -g nestforge
```

## Usage

```bash
nestforge --help
```

## Platform Support

| Package | OS | Architecture |
|---------|----|-------------|
| `@nestforge/cli-darwin-arm64` | macOS | ARM64 (Apple Silicon) |
| `@nestforge/cli-linux-x64` | Linux | x86_64 |
| `@nestforge/cli-win32-x64` | Windows | x86_64 |
